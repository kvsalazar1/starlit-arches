Your calendar connection

Privacy policy

Effective October 22, 2026

This policy covers the Google Calendar feature of Starlit Arches, a personal Windows utility that displays calendar information in Rainmeter. It explains what the utility accesses and what remains on your computer.

The purpose is simple: show your calendars in an agenda and a month view. The utility does not create, edit, or delete Google Calendar events.

What Google access is requested

You choose whether to connect Google Calendar. Sign-in and permission approval take place on Google's browser page. Starlit Arches requests two permissions:

  • calendar.events.readonly — read events on calendars available to your account.
  • calendar.calendarlist.readonly — read your subscribed-calendar list so you can identify and filter calendars.

These permissions do not provide event-writing access. The utility does not receive or store your Google password.

The helper downloads events from the accessible, non-hidden calendars returned by Google. The switches in each widget affect display only; hiding a calendar in a widget does not exclude its events from the downloaded snapshot.

The helper does not request event descriptions, locations, or attachments.

Storage on your computer

The default event-cache and connection folder is %USERPROFILE%\.starlit-arches\GoogleCalendar. It is separate from the Rainmeter skin folder.

Windows Data Protection API (DPAPI), tied to your Windows user account, encrypts the saved client configuration and sign-in tokens. The event cache is a readable local data file; it is not encrypted by the application. Setup encrypts the client configuration it saves, but leaves the original downloaded Desktop app JSON wherever you kept it.

Calendar-filter preferences are saved in the Agenda and Month Rainmeter configuration files. Those preferences can contain calendar identifiers, encoded for the configuration format. If your Rainmeter folder is in OneDrive or another synced location, those preference files may be synced by that service.

The utility does not place its default event cache or connection files in OneDrive. Your Windows settings, backups, security tools, or sync software can still affect files on your computer; this policy does not describe those providers' independent processing.

Use, network requests, and sharing

The calendar helper makes HTTPS requests directly to Google's authorization and Calendar API endpoints. Sign-in temporarily uses a local loopback receiver on your computer to finish authorization.

Starlit Arches uses the downloaded information to display and filter your calendar views and retain a useful snapshot during connection failures. There is no Starlit Arches calendar backend, analytics service, advertising system, or remote-sharing feature. The calendar utility does not sell data or use it for advertising, profiling, or training AI models.

Google handles sign-in and API requests under Google's privacy policy. This static information website has no calendar sign-in, forms, advertising, analytics scripts, or application tracking cookies. A website host can process ordinary request metadata under its own policies; calendar information is not uploaded to this site by the utility.

Google API Limited Use

Starlit Arches is committed to following the Google API Services User Data Policy, including its Limited Use requirements. Google API data is used for the visible personal-calendar features described here. The utility contains no feature for selling this information, sending it to advertising platforms, or providing it to another application server.

This is a description of the utility's practices and commitment, not a claim of Google certification or verification.

Retention and disconnecting

A successful refresh replaces the local snapshot. On a failed refresh, the last successful snapshot can remain with an offline status. Cache and connection files remain until replaced or deleted; revoking Google access does not erase files already saved on your computer.

  1. Unload both Agenda and Month in Rainmeter to stop automatic calendar polling.
  2. Open your Google Account connections, select this application, and remove its access. Google's instructions explain the process.
  3. To remove the local snapshot and encrypted connection, delete the %USERPROFILE%\.starlit-arches\GoogleCalendar folder.
  4. To remove remembered calendar-filter identifiers, clear CalendarHiddenIds in both calendar widgets' configuration files, or remove those calendar skins. Manage any backups or other copies separately.

Changes to these practices

Any material change to the calendar data accessed or its purpose should be reflected in this policy and disclosed before the utility begins that new use. A new use requiring additional Google permissions must be separately authorized.
